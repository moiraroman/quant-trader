# Task Artifact - Fix 4 Broken Tabs

## Problem
All 4 tabs (AI分析, 实盘交易, 策略优化, 系统设置) crashed with:
```
AttributeError: 'PaperTrader' object has no attribute 'get_trade_history'
```

## Root Cause
app.py line 1052 called `trader.get_trade_history(days=30)` but `PaperTrader` class in `trading/paper.py` didn't have this method.

## Fix
Added two methods to `PaperTrader` class:
1. `get_trade_history(days=30)` - reads from storage
2. `get_equity_curve(days=30)` - reads from storage

Both methods return empty DataFrame if storage is unavailable.

## Files Modified
- `trading/paper.py` - Added get_trade_history() and get_equity_curve()

## Verification
- py_compile passed for both paper.py and app.py
